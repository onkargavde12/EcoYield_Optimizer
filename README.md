**Ecoyield-Optimizer**

This EcoYield-Optimizer project uses an image dataset from Kaggle, organized into folders of disease detected and without disease detected images for training and testing. The model is trained to analyze leaf images and detect diseases of that plant. By classifying images disease detected and without disease detected, this project aims to create a tool for identifying diseases of the plant. Dataset: https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset
